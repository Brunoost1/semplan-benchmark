# Frozen derived results

`SemPlan_results_v1.0.zip` contains the frozen derived CSV tables supporting the manuscript's reported metrics and paired comparisons.

These files are derived scientific outputs, not raw provider responses. Raw provider payloads and private working artifacts are not part of this public repository.

Latency values are retained only for completeness and are not used as primary comparative evidence because captured typed failures recorded zero latency in the frozen runner.
